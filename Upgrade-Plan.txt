Keybchord improvement plan:
- Chord engine upgrades:
  - Add chord roll parameter, i.e. playing the notes of a chord not all at once/adding time between each note. Applies to held and press mode
    - chord roll parameter can be positive (playing the notes upward) or negative (playing the notes downward) and should be in ms (incrementing by 5)
  - Add minimum number of notes in chord. By default is 3, but if value is 4, C major becomes CEGC (while Cmaj7 is still CEGCB). If value is 5, becomes CEGCE and cmaj7 becomes CEGBC
  - Add additional voicing options
    - minimum interval (steps) between notes: if the minimum interval is 5 steps (perfect 4th), no two notes in the played chord can be less than 5 steps/semitones apart. So for a C with the root C3, a minimum interval of 1, the C chord would play notes C3 E3 G3 since C3->E3 is >= 1 step and E3->G3 is >= 1 step. If the minimum interval is 5, the chord played would be C3 G3 E4, since C3 -> E3 (closest possibility) is < 5 steps. Important note: the chords should be structured together in the tightest possible configuration - i.e. if the minimum interval was 4, C3->E3 would be valid, but E3->G3 would not. In this case, the notes chosen should be C3->G3->E4, since C3->E3->G4 would cover a larger distance
	- toggleable inversions: I want the unused keys PrtSc, ScLk, and Pause to be used to switch between first, second, and third inversion, i.e. determine whether the 1st, 3rd, or 5th of the chord is treated as the root
	- Arpeggio upgrades:
	  - Add arpeggio modes:
	    - Up: plays starting with the lowest note of the chord, up through the highest, then cycles to lowest (already implemented)
		- Down: inverse of up - start with the highest note, play down, loop back to highest
		- Up-Down: start with the lowest note, play up through the highest, then down back to the lowest, and repeat
		- Alternating: chord notes play 1->3->2->4 
		- Random: random notes in the chord are played 
  - Make left/down/right keys "held" keys instead of toggle keys. i.e. if I play a C while left is held, the 9th will be added to the played chord. This should latch for the current chord, and should add to any currently played chord, e.g. if I am holding down T to play a C chord, and then press left, it should add the add9 to the current chord
    - Remove add9/11/13 as a configurable parameter - only activated by holding left/down/right while playing a chord
  - Rhythm chord mode should cause the chord to be played along with the rhythm like the original omnichord, with the bass note of the chord being played on the downbeat. Look at how the original omnichord rhyhthm mode worked for examples.
- Strum engine upgrades:
  - Duration should represent minimum duration, i.e. if a key is held for longer than the duration, the note should continue to be held
  - Add strum mode selection:
    - Default is follow-chord (currently implemented)
	- Scale mode: selectable root and scale/mode (major, minor, dorian, etc. - should include standard major/minor/harmonic/melodic scales, the 7 modes, and pentatonic and blues scales)
    - Piano mode: selectable root, each number is a half step up from the last
- Rhythm engine updgrades:
  - Selectable note/drum code per drum piece (by piece I mean kick vs hi hat vs snare etc): add a sub-menu to the rhythm menu to allow editing each drum piece to use a different code (for non standard synths) - title should be "snare" "kick" "hi hat" etc and the bottom line should say the code that is currently selected. When cycling through it using up/down, the sound should be played once so that the user can hear it
  - Velocity per drum piece
